# 連作投稿フォーム | 縦書き組版・LaTeX

短歌同人誌・結社誌の寄稿用に特化した、**連作入力フォーム・リアルタイム縦書き組版プレビュー・LaTeX自動出力Webツール**です。

---

## 🌟 主な機能

1. **実用的な投稿フォーム**
   - 連作タイトル、作者名、詞書、短歌本文の入力欄
   - 余計なプレースホルダー（背景文字）のない、清潔で直感的な入力ボックス
   - 「＋ 歌を追加する」「削除」「入力内容をクリア」
2. **Akkas タイル状ルビ入力システム**
   - **短歌本文・詞書の両対応**: モーダル内で「短歌本文」「詞書」をワンクリックで切り替え可能
   - **漢字選択**: 短歌・詞書内の熟語を自動抽出し、ワンタップで親文字に指定
   - **文字タイル**: 短歌の各文字を独立したタイルとして表示。1文字タップまたは開始・終了タップによる範囲選択に対応
   - **正確なピンポイント置換**: 同一単語が複数回登場する場合（例:「花は花でも…」）でも、選択したインデックス位置のみを確実にルビ化
   - **ルビピル**: 既にルビが振られた箇所はルビ付きピルとして可視化され、直感的な再編集や解除が可能
3. **完全ローカル・自動保存・入力保護**
   - HTML / CSS / Vanilla JavaScript のみで構成（外部通信なし、GitHub Pages等で即動作）
   - `localStorage` へのリアルタイム自動保存
   - 歌削除時の確認ダイアログ（誤操作防止）
   - 日本語IME入力の最適化（変換確定に連動した滑らかなデバウンス描画）
4. **リアルタイム縦書き組版プレビュー**
   - CSS `writing-mode: vertical-rl;` による本格的な歌集組版
   - 右から左へ流れる横スクロール（通常のマウスホイールでも自然に連動）
   - 冒頭に「連作タイトル」「作者名（地付き）」を配置
   - 詞書がある歌は、歌の直前にフォントサイズ縮小＆上部字下げで視覚的に区別
   - `｜親文字《ルビ》` 記法をHTML `<ruby>` / `<rt>` に自動変換（JIS X 4051準拠）
5. **厳格なLaTeX出力仕様**
   - LaTeX特殊文字（`%`, `_`, `&`, `$`, `#`, `{`, `}`, `^`, `~`, `\`）の自動エスケープ処理
   - 未入力の空カードは自動除外
   - プリアンブル（`\usepackage` 等）を含まず、本文に直接取り込める形式
   - 詞書なし: `\uta{}`（前後に空行）
   - 詞書あり: `\kotobagaki{}` と `\uta{}` を `tanka` 環境でマークアップ
   - ルビ: すべて `\ruby[g]{親文字}{ルビ}` に変換
   - ワンクリックでコードをクリップボードにコピー

---

## 📋 LaTeX出力仕様

```latex
\begin{rensaku}
    \title{連作タイトル}
    \author{作者名}

        \uta{詞書のない一首目}

        \uta{詞書のない二首目}

        \begin{tanka}
            \kotobagaki{詞書}
            \uta{詞書のある三首目}
        \end{tanka}

\end{rensaku}
```
